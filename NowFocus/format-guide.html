💡 Note Format Guide

Weekly Plan Structure

Create a note with the following structure:

# 20251229-20260104 周计划

## 本周计划

| 大目标 | 小目标 | 交付 |
|--------|--------|------|
| Complete Feature A | Design | Done |
| Complete Feature A | Development | |

---

## 周四: Task Manager

**今日目标**
- Complete core functionality
- Testing and validation

| 时间段 | 任务 | 交付 |
|--------|------|------|
| 10:00-12:00 | Development | done |
| 14:00-15:00 | Meeting | |
| 15:00-17:00 | Code review | Completed review |

Key Points

  • Time Format: Use HH:MM-HH:MM format
  • Completion: Add any text in the "交付" (Delivery) column to mark as done
  • Daily Section: Start with day of week: 周X: or M/D 周X
  • Today's Goals: Use bullet points with -
