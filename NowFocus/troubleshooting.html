🔧 Troubleshooting

Mac App Issues

App doesn't appear in menu bar

Check if the app is running in Activity Monitor. Try quitting and relaunching. Make sure LSUIElement is properly configured (this is automatic - contact support if issue persists).

Can't read Notes / Permission denied

Go to System Preferences → Privacy & Security → Automation, find NowFocus, and ensure Notes is checked. If the issue persists, try removing and re-granting the permission.

Floating window doesn't show

Click the menu bar icon and select "Show Desktop Widget". If it still doesn't appear, try quitting and restarting the app.

iOS App Issues

Widgets not updating

Remove and re-add the widget. Ensure the Mac app is running and syncing. Check iCloud Drive status in Settings. Widget updates are controlled by iOS and may take up to 15 minutes.

Live Activities not appearing

Check that Live Activities are enabled: Settings → NowFocus → Live Activities. Also verify Focus mode settings aren't blocking Live Activities.
